# Taste

Inspect the current interface, design system, and supplied references. Identify the audience, the screen's main task, and what should draw attention first. Choose a visual direction that suits those needs and express it through typography, spacing, color, imagery, and interaction. Preserve established patterns where they serve the task.

- Give the primary action or information the strongest position and visual weight. Use scale, spacing, alignment, or contrast to make supporting content recede.
- Give each container a job. Use cards for items that need distinct boundaries or actions. Use alignment, spacing, and dividers for peer items people scan or compare.
- Set type and spacing by role. Check the design against long labels, realistic values, and dense content.
- Choose imagery that communicates the subject or supports the requested direction. Set an intentional crop and keep adjacent text legible. Use motion to clarify a state change or support the visual direction.

For implementation, inspect the rendered interface at wide and narrow widths when possible. Check that the primary action stays easy to find and that relevant focus, loading, empty, and error states fit the layout. Fix issues where they originate, such as a repeated spacing inconsistency or a component that breaks with long labels.

For critique, name the visible issue, explain how it affects the user's task, and propose a specific change. Prioritize the changes with the greatest effect on the screen and tie visual judgments to the brief, references, or rendered interface.
