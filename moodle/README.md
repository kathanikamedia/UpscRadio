# Free introductory mock setup

The original 10-question quiz is in free-polity-starter.gift. Its introductory difficulty is intended for a first practice session.

1. Create a Moodle course for the free starter mock.
2. Import the GIFT file into its question bank and create a Quiz with all 10 questions.
3. Set 15 minutes, one mark per question, deferred feedback and one permitted attempt. Leave negative marking disabled. Allow answer and explanation review after submission.
4. Enable manual enrolment and confirm that the website service account can enrol students.
5. In the website staff editor, open free-polity-starter. Keep its fee at zero and save the Moodle course ID.
6. Verify Clerk sign-in, free enrolment, one-time Moodle login, question timing, submission and results using a student account.

The website reserves this slug as its only free mock. Other mock tests require a fee of at least 100 paise before publishing. Pricing is awaiting the institute's input. Paid checkout also requires a Moodle course mapping and configured Razorpay credentials.
